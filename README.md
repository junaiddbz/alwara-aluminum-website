# Alwara Website

**Website:** [https://alwaraaluminum.com/](https://alwaraaluminum.com/)

A static website for Alwara, showcasing products like doors, kitchens, shutters, washrooms, and windows.

## Structure
- `index.html`: Main landing page (Arabic/Default)
- `en.html`: English landing page
- `doors/`, `kitchen/`, `shutters/`, `washroom/`, `window-walls/`, `windows/`: Product categories and related assets.
